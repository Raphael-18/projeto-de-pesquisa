# Modelo acoplado chuva-vazão em Python

## Introdução
Este repositório contém um modelo acoplado chuva-vazão em Python.
O Modelo Chuva-Vazão utilizado é o SMAP diário, em que as precipitações são previsões e o routing é feito pelo método de Muskingum de jusante para montante.

## Estrutura do repositório
```
├───Dados
├───Metodos
│   └───Muskingum
└───Scripts
    ├───Modelo
    └───Resultados
```
